WHAT YOU’LL LEARN

อยากสร้างเว็บหรือแอปเอง?
เรียนแบบจับมือทำกับโปรเจกต์ของคุณ

ไม่ได้สอนแค่ให้ AI เจนโค้ด แต่พาเข้าใจกระบวนการพัฒนาระบบจริง ตั้งแต่วิเคราะห์ปัญหาและผู้ใช้งาน วาง Requirement, System Flow, Database, หน้าจอและโครงสร้างระบบ ก่อนใช้ AI ช่วยพัฒนาและแก้ปัญหาจนเป็นโปรเจกต์ของคุณเอง

01

วิเคราะห์ Requirement

แตกไอเดียของคุณเป็นขอบเขตงาน ผู้ใช้งาน ฟังก์ชัน และสิ่งที่ระบบต้องทำให้ชัดก่อนเริ่มเขียน

02

System Flow + Architecture

วางลำดับการทำงานของระบบ Frontend, Backend, API และบริการต่าง ๆ ให้ AI เข้าใจภาพเดียวกับเรา

03

ออกแบบ Database

วาง Table, Field, Primary Key, Foreign Key และ Relationship ให้เหมาะกับโปรเจกต์จริงของผู้เรียน

04

UI / UX + หน้าจอ

กำหนดว่าระบบต้องมีหน้าอะไร แต่ละหน้ามีข้อมูล ปุ่ม ฟอร์ม และการเชื่อมโยงอย่างไร ก่อนให้ AI ลงมือสร้าง

05

AI Coding + Debug

เรียนวิธีแบ่งงานให้ AI เขียนทีละส่วน อ่าน Error ตรวจโค้ด สั่งแก้ และเพิ่ม Feature โดยไม่ทำของเดิมพัง

06

Test + Deploy

ทดสอบ User Flow และข้อมูลจริง ตรวจจุดผิดพลาด แล้วนำเว็บไซต์หรือแอปขึ้นใช้งานและเรียนวิธีพัฒนาต่อเอง
